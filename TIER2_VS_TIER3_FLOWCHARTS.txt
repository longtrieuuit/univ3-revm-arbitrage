TIER 2: EXECUTING 1 SWAP (revm_call)
═══════════════════════════════════════════════════════════════════════════════════

Input: volume = 0.1 WETH


Step 1: Build Calldata
──────────────────────
    calldata = quote_calldata(0.1 WETH)
                            ↓
         ┌──────────────────────────────────┐
         │ Encode ABI:                      │
         │ quoteExactInputSingle(           │
         │   tokenIn=WETH,                  │
         │   tokenOut=USDC,                 │
         │   fee=3000,                      │
         │   amountIn=0.1 WETH              │
         │ )                                │
         │           ↓                      │
         │ Result: 0xf3bdc138ab12cd... (4+32+32+32+32)
         └──────────────────────────────────┘
    Time: <1ms


Step 2: Create Transaction
──────────────────────────
    tx = build_tx(V3_QUOTER_ADDR, ME, calldata, base_fee)
                            ↓
         ┌──────────────────────────────────┐
         │ Create unsigned transaction:     │
         │ {                                │
         │   from: ME,                      │
         │   to: V3_QUOTER_ADDR,            │
         │   data: calldata,                │
         │   gas_price: base_fee,           │
         │   ...                            │
         │ }                                │
         └──────────────────────────────────┘
    Time: <1ms


Step 3: Execute in REVM (Cache Hit!)
─────────────────────────────────────
    response = revm_call(ME, V3_QUOTER_ADDR, calldata, &mut cache_db)?
                            ↓
         ┌──────────────────────────────────────┐
         │ REVM Execution:                      │
         │                                      │
         │ 1. Check cache_db.memory:            │
         │    [V3_QUOTER_ADDR] = bytecode ✅   │
         │    (Found! No RPC needed!)           │
         │                                      │
         │ 2. Create REVM context               │
         │    context.transact(tx)              │
         │                                      │
         │ 3. Execute bytecode:                 │
         │    - Load function selector          │
         │    - Parse arguments                 │
         │    - Call pool.swap()                │
         │    - Pool executes swap              │
         │    - Return output                   │
         │                                      │
         │ 4. Capture output data               │
         │    amount_out = 200 USDC             │
         │    sqrtPrice = ...                   │
         │    tick = ...                        │
         │                                      │
         │ 5. Return response bytes             │
         └──────────────────────────────────────┘
    Time: ~35ms (IN-MEMORY!)
    Network: ZERO RPC calls! ✅


Step 4: Decode Response
───────────────────────
    (amount_out, sqrtPrice, ...) = decode_quote_response(&response)
                            ↓
         ┌──────────────────────────────────┐
         │ Parse response bytes:            │
         │ offset 0: amountOut = 200 USDC   │
         │ offset 32: sqrtPrice = ...       │
         │ offset 64: tick = ...            │
         │           ↓                      │
         │ ✅ Decoded: 200 USDC             │
         └──────────────────────────────────┘
    Time: <1ms


Step 5: Use Result
──────────────────
    println!("0.1 WETH → 200 USDC")
                            ↓
         ┌──────────────────────────────┐
         │ Output to user                │
         │ ✅ 200 USDC                   │
         └──────────────────────────────┘
    Time: <1ms


TIER 2: Total per call: ~35ms (from cache!)
